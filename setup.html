Add the search shortcut to your browser

Your browser sends whatever you type after the shortcut to this address:

{{.Base}}/?q=%s

Then type pr 5219 in the address bar to go straight to pull request 5219. Add part of a repository name, like pr 42 ios, to pick one when several repositories have that number.

Chrome, Brave, Edge, Opera and Vivaldi · your browser

Opening this page told your browser about pr-jump, so it is already waiting in your settings.

  1. Open your browser's search engine settings: type chrome://settings/searchEngines in the address bar (Brave: brave://settings/searchEngines, Edge: edge://settings/searchEngines, Opera: opera://settings/searchEngines).
  2. Under Site search, find pr-jump in the inactive shortcuts and choose Activate. If it is not there, choose Add and paste the address above.
  3. Edit it and set the shortcut to pr.

Vivaldi: Settings, then Search, then add a search engine with the nickname pr and the address above.

Firefox · your browser

  1. Click the search engine button at the left of the address bar, or the page actions menu, and choose Add "pr-jump".
  2. Open Settings, then Search. Under Search Shortcuts, double-click the keyword next to pr-jump and type pr.

Or add a bookmark with the address above as its URL and pr as its keyword.

Safari · your browser

Safari cannot add its own search shortcuts. Use a Safari extension that supports keyword searches, and give it the address above.
