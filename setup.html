Add the pr shortcut to your browser

  1. Copy the search address

    Your browser sends whatever you type after the shortcut to this address.

    {{.Base}}/?q=%s

  2. Add it to your browser as pr

    Chrome, Brave, Edge, Opera and Vivaldi Your browser

    Opening this page told your browser about pr-jump, so it is already waiting in your settings.

    1. Open your browser's search engine settings by typing its address in the address bar:
      • Chromechrome://settings/searchEngines
      • Bravebrave://settings/searchEngines
      • Edgeedge://settings/searchEngines
      • Operaopera://settings/searchEngines
    2. Under Site search, find pr-jump in the inactive shortcuts and choose Activate. If it is not there, choose Add and paste the address from step 1.
    3. Edit it and set the shortcut to pr.

    Vivaldi: open Settings, then Search, and add a search engine with the nickname pr and the address from step 1.

    Firefox Your browser

    1. Click the search engine button at the left of the address bar, or the page actions menu, and choose Add "pr-jump".
    2. Open Settings, then Search. Under Search Shortcuts, double-click the keyword next to pr-jump and type pr.

    Or add a bookmark with the address from step 1 as its URL and pr as its keyword.

    Safari Your browser

    Safari cannot add its own search shortcuts. Use a Safari extension that supports keyword searches, and give it the address from step 1.

  3. Try it

    Type pr 5219 in the address bar to go straight to pull request 5219.

    If several repositories have that number, add part of a repository name, like pr 42 ios.
